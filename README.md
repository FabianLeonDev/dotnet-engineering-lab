# dotnet-engineering-lab
A hands-on laboratory for exploring .NET engineering concepts through small, independent experiments.

Each experiment focuses on a specific topic, with an emphasis on understanding behavior, trade-offs, performance characteristics, and practical implementation details.

## Areas
- Async — asynchronous programming and execution models
- Concurrency — synchronization, parallelism, and concurrent workloads
- Memory — allocations, garbage collection, and memory behavior
- ASP.NET — web application and framework experiments
- Performance — benchmarking, profiling, and optimization
- Testing — testing strategies, tooling, and test performance
- Data — data access, serialization, storage, and related experiments

Experiments are intentionally isolated and self-contained, making the repository a space for learning, experimentation, measurement, and technical investigation.
